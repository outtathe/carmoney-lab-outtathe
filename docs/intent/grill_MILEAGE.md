## Намерение
В расчёт решения по заявке добавить правило «пробег авто не больше 400 000 км,
иначе решение review». Правило меняет решение, не валидацию: заявки с пробегом
вне [0; 500 000] по-прежнему получают 422 (vehicle.max_mileage_km) и до
расчёта решения не доходят.

## Зафиксированные решения
1. Граница включительная: ровно 400 000 решение не понижает; триггер —
   строго больше 400 000 (400 001 → понижение).
2. Приоритет: перепробег — только понижающий фактор: approve → review;
   review и reject не меняются (reject не смягчается).
3. Пустая строка пробега приводится к 0 км и проходит — существующее
   поведение сохраняется; отсутствие поля / null → 422. Валидатор не трогаем.
4. approved_limit при понижении до review = 0 (существующая логика assess()).

## Границы значений
- 399 999 — решение по LTV; 400 000 — решение по LTV; 400 001 — approve → review.
