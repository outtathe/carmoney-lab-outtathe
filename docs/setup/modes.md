# Режимы работы Kilo

## ask
Режим для вопросов и консультаций. Не выполняет изменения в коде.
Используется для:
- Поиска информации в кодовой базе
- Ответов на технические вопросы
- Планирования задач
- Анализа архитектуры

## code
Режим для реализации задач. Выполняет изменения в файлах.
Используется для:
- Написания и редактирования кода
- Рефакторинга
- Исправления багов
- Запуска тестов и линтеров

## Агенты для разбора кода

| Агент | Назначение |
|-------|------------|
| **explore** | Быстрый поиск файлов, символов, паттернов. Подходит для: "где находится X", "как работает Y", обзора структуры. Уровни: `quick`, `medium`, `very thorough`. |
| **general** | Многошаговые задачи, требующие рассуждений: анализ зависимостей, построение диаграмм, аудит безопасности, сложный рефакторинг. |

**Рекомендация**: для первичного разбора кодовой базы начните с `explore` (quick/medium), затем при необходимости переключитесь на `general` для глубокого анализа.
